分析

已知 p 为 198bit 素数，直接跑 Pollard rho 不可行，之后发现这条曲线是超奇异曲线。

对于任意一条定义在素数 p 上的椭圆曲线，根据哈斯定理，其有效点的总数严格被约束于 p+1−2p≤N≤p+1+2p ，也写成 N=p+1−t ，其中 t 叫做误差项（Frobenius 迹），而超奇异曲线的误差项严格为 0 ，曲线点数严格为 p+1 个。

对于本条曲线 y2≡x3+3x(modp) （其中 p 为 4k+3 型素数。这种素数构成的有限域中，一对相反数必然一个是平方剩余，另一个是非平方剩余），右边是一个奇函数。那么对于 x,−x ，必定满足有且只有一个能求出两组对应 y 值，另一个不产生 y 值。

我们有 p−12 组相反数，每对贡献精确的两个点。当 x=0 时，贡献一个点，外加一个无穷远点。故曲线的总点数为 (p−1)+1+1=p+1 ，本条曲线是超奇异曲线。

这类曲线在传统的 ECDSA 中被认为是不安全的，在后量子密码中却是热门的研究对象。

分析

md5 的哈希长度扩展攻击。假定原始数据为 key + message（注意一定是 key 在前），md5 会把原始数据填充到长度模 64 为 56 的状态，记这个填充为 padding，我们最终想要追加的数据为 append。那么根据 md5 的缺陷，我们可以构造出消息 key + message + padding + append 的哈希（而非 key + message + append 的，这无法实现）

在这个过程中，我们无需确定 key 的具体长度，只需确定 key + message 占了几个 64 字节块就可以（因为二次 md5 时末尾需要追加总长度）

参考这个项目：shellfeel/hash-ext-attack: 哈希长度扩展攻击利用脚本，免去了 hashpump 需要编译的烦恼

分析

ECDSA 签名生成：

  1. 选取随机数 k，计算 R=k⋅G ，其中 G 为因曲线而异的公开基点
  2. r=R.x ， s=k−1⋅(e+dr)modn （其中 e 为消息哈希， d 为私钥， n 为公开的曲线阶）

由于随机数 k 是由 5 级 LFSR 生成的，其状态空间为 31，故当请求 32 个签名时第 0 个和第 31 个必定复用。

k 相同引起 r 相同。设重复的两次的消息哈希分别为 e1,e2 ，那么可以解出 k 本身：

k=(e1−e2)⋅(s1−s2)−1modn

有了 k ，将其代入原方程就能得到私钥 d 。解出私钥之后，服务端要求使用固定的 r 对固定消息进行签名，最终提交 s=k−1⋅(e+dr)modn 。

在 ECDSA 中，随机数 k 的取值范围是 [1,n−1] ，基点固定。由于 r 是生成点的一部分，没办法反推，所以还是只能爆破 k。好在 k=1 ，一下就能出来。

用 k=1 签，报错 Unfortunately，you're not the chosen one.Try another method to pass my test 打回了。折腾半天发现需要用 k=−1 签。。。

提交签名的 s 得 flag。
