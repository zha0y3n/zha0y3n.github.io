安装 WSL

什么是 WSL

WSL 是 Windows Subsystem for Linux 的缩写，即“适用于 Linux 的 Windows 子系统”。它让你能在 Windows 上直接运行 Linux 命令行、工具和程序，无需安装虚拟机或双系统。WSL2 使用真实 Linux 内核，性能和兼容性更好。

为什么要安装 WSL

主要还是因为 sagemath 撤销了对 Windows 的支持。另外以后如果跑 agent 的话，在 Windows 环境下 powershell 命令容易被写坏，agent 对 Linux 命令的支持度更高。再者，想学 Linux 命令、测试部署环境，或使用 Docker、Git 等工具时，WSL 是很方便的选择。

语法差异

如果题目刚需 sage 环境（比如涉及到 coppersmith、ECC 以及格密码时），只依靠交互环境是很费劲的，这个时候就需要编写 sage 脚本解题。但是目前 .sage 没有成熟的代码补全和高亮。虽然 python 能导入 sage 库（from sage.all import *），能够享受 lsp，但是语法却有许多限制。对比一下 sage 写法和 python 写法的差异：

  1. 对于精确有理数（如 13 ）：sage 写 a = 1/3 能精确保留，python 需要额外写成 a = QQ(1)/3

  2. 幂运算：sage 用 ^（异或是 ^^），python 用 **（异或是 ^）

  3. 单变量多项式环：R.<x> = QQ[]，python中取生成元是x = QQ["x"].gen()，取环是R = QQ["x"]。二者都要的话要写成两句：R = QQ["x"]; x = R.gen()

    类比所有带 .<x> 形式的语法，python 都不能直接用（如多变量多项式环，商环，数域等等）

  4. 连续步长的列表：[1..5]，这个语法糖的意味太重了，python 是 list(range(1, 5+1))

大概就只有这么多，其它的 sage 语法在 python 编辑器里不会报错，可以照常写。

直接写 .sage 脚本可以享受更便捷的语法，但是失去了高亮和补全。写 .py （这里指调用 sage 库函数的脚本）正好相反，语法复杂一些，但是体验更好。

修改扩展（可选）

SageMath Enhanced 扩展有些地方用着不是很顺手：

  1. 当你试图按住 ctrl 以查看类 / 方法的定义时（其实更可能是按快捷键时鼠标不小心移到了上面），扩展会报错 Request textDocument/definition failed.，且这个报错不能静默。
  2. 写矩阵时如果分行写会报警告（原因是原扩展只维护了同一行的括号栈），Unmatched parentheses on line x
  3. 点击右上角的 Run SageMath File 小箭头后文件不会自动保存，只按照旧脚本运行。
  4. （可选的优化）保存时若代码末尾无空行，则新增一个空行并将光标移动到该空行上。
